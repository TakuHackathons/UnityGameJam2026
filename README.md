# UnityGameJam2026

Our team is building a game in Unity for the [Official 2026 Unity Game Jam](https://itch.io/jam/official-unity-game-jam-2026).

## Jam Theme: Lucky Number

A lucky number is a number someone associates with good fortune, whether through personal belief, cultural tradition, or symbolism. The jam invites teams to explore luck, fate, and superstition through gameplay, art, and sound.

## Project Status

In development for the jam. Our goal is to submit a playable build and explore developing it further for a release after the event.

**Submission deadline:** November 14, 2026 at 12:00 UTC.
